# Week 1 — `T00` CF literacy & implementation

**Phase:** 0 — CF literacy  
**Rating band:** 800–1000 (stretch 1200–1300)  
**Dates:** 2026-08-28 → until Toffy reports

## Overview

First week is **how Codeforces feels**, not new algorithms. Read the statement, treat samples as a contract, look at constraints, then implement the ugly obvious thing without inventing graphs or DP.

Roadmap: **T00**. Deep enough = a new 800–1000 `implementation` problem doesn’t make you fight the platform (I/O, 1-based indexes, “just simulate it”). If this whole set feels like baby LeetCode, say so in the report and we’ll bump the band — don’t skip the CF-style traps though (`131A` exists for a reason).

### Intro resources (optional, 1–3)

- [Time complexity vs constraints](https://usaco.guide/bronze/time-comp) — look at `n` *before* you code
- [Integer overflow](https://codeforces.com/blog/entry/21851) — why `int` dies on easy-looking math

Problems below are **Codeforces only**. Resources are for the topic, not extra homework from other OJs.
