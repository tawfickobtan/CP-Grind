# Week 2 — `T01` Simulation, ad-hoc, casework

**Phase:** 0 — CF literacy  
**Rating band:** ~1100–1500 (stretch 1400–1600)  
**Dates:** 2026-09-01 → until Toffy reports

## Overview

Same CF muscle as week 1, thicker problems. **No new named algorithm.** The statement *is* the algorithm: simulate the process, split cases, debug on a tiny example. If you catch yourself reaching for DP/graphs, stop — you’re inventing.

Roadmap: **T01**. Deep enough = a messy 1300-ish “just do what it says” problem doesn’t scare you into theory. About 10 core so you can sit with each one. Calendar can run past 7 days.

### Intro resources (optional, 1–3)

- Look at `n` first. If it’s small, **simulate**. If the statement lists rules, **code the rules**.

Problems below are **Codeforces only**. Resources are for the topic, not extra homework from other OJs.
